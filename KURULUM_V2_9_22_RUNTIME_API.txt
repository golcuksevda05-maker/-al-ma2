3. Sorarsa üzerine yaz.
4. Programı çalıştır:

1. Önce en az bir Pragmatic rulet masası açık olsun.
2. KAYITLI MASALARI API'DEN YENİLE'ye bas.
3. Durum satırında OK/HATA değerlerini izle:
   API TOPLA: çalışıyor • OK X / HATA Y • 6 aktif • Z bekliyor
