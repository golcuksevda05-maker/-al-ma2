ROULETTE PRO AI V2.9.24 DGA LIVE KURULUM

KURULUM
1. ZIP dosyasını tamamen klasöre çıkar.
2. İçindeki dosyaları mevcut program klasörüne kopyala.
3. Sorarsa üzerine yaz.
4. Programı çalıştır:
   BASLAT_ROULETTE_V2_9_12_MULTI_TABLE_COLLECTOR.bat

KONTROL
- Üst başlıkta V2.9.24 DGA LIVE yazmalı.

KULLANIM
1. Chrome'da en az bir Pragmatic rulet masası veya Pragmatic lobi açık olsun.
2. Programda şu düğmeye bas:
   KAYITLI MASALARI DGA CANLI YENİLE
   veya
   DGA CANLI / MASALARI TARA
3. Durum satırında şunlardan biri görünmeli:
   DGA CANLI: bağlı • ... masa abone • veri bekleniyor
   DGA CANLI: ... masa güncellendi
4. Bu sürümde hedef OK/HATA sayacı değildir. DGA feed yeni spin geldikçe masa
   arşivini günceller.
5. Durdurmak için TARAMAYI DURDUR'a bas.

ÖNEMLİ
- Eski statisticHistory API senin operatörde OK vermediği için bu sürüm API
  yerine DGA WebSocket canlı feed'i ana çözüm olarak kullanır.
